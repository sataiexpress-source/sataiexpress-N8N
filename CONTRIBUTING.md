# Contributing to SatAI Express

Thank you for your interest in contributing to our n8n workflow collection! 🎉

## 🤝 How to Contribute

### Reporting Bugs

If you find a bug in a workflow:

1. Check if the issue already exists in [GitHub Issues](https://github.com/sataiexpress-source/sataiexpress/issues)
2. If not, create a new issue with:
   - Clear title describing the problem
   - Steps to reproduce
   - Expected vs actual behavior
   - n8n version and environment details
   - Screenshots if applicable

### Suggesting Features

We welcome feature suggestions! Please:

1. Open an issue with the `enhancement` label
2. Describe your idea clearly
3. Explain the use case and benefits
4. Provide examples if possible

### Submitting Workflows

Want to share your n8n workflows? Great!

#### Workflow Submission Guidelines

1. **Test Thoroughly**: Ensure your workflow is tested and working
2. **Remove Credentials**: Export workflow WITHOUT any credentials or API keys
3. **Document Well**: Add clear comments within the workflow
4. **Provide Documentation**: Include a description of:
   - What the workflow does
   - Prerequisites and dependencies
   - Required credentials
   - Setup instructions
   - Example use cases

#### Submission Process

1. Fork this repository
2. Create a new branch: `git checkout -b workflow/your-workflow-name`
3. Add your workflow JSON file
4. Update README.md to include your workflow in the table
5. Create a pull request with:
   - Clear description
   - Screenshots or demo (if applicable)
   - Testing notes

## 📝 Workflow Naming Convention

- Use descriptive names: `Email Newsletter Generator.json`
- Use title case
- Avoid special characters except spaces and hyphens

## 🔒 Security Requirements

- **Never** include API keys, passwords, or credentials
- **Never** include personal or sensitive data
- Review your workflow JSON before submitting
- Use placeholder values for configuration

## ✅ Code of Conduct

### Our Standards

- Be respectful and constructive
- Welcome newcomers
- Focus on what's best for the community
- Show empathy towards others

### Unacceptable Behavior

- Harassment or discriminatory language
- Trolling or insulting comments
- Publishing others' private information
- Other unprofessional conduct

## 📞 Questions?

Feel free to open an issue with the `question` label or start a discussion in [GitHub Discussions](https://github.com/sataiexpress-source/sataiexpress/discussions).

Thank you for contributing! 🙌
